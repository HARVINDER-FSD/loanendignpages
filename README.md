# Loan Lending Landing Pages (3 Independent Websites)

This repository contains **3 separate, self-contained loan lending landing pages**, ready to be hosted independently on any web host (Netlify, Vercel, cPanel, Apache/Nginx, Hostinger, GitHub Pages, etc.).

---

## 📁 Project Structure

- **Folder**: `landing-1/`
- **Main File**: `landing-1/index.html`

## 🚀 How to Host Separately

### Option A: Netlify / Vercel Drag & Drop
1. Open [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the `landing-1` folder to deploy Website 1.
3. Drag and drop the `landing-2` folder to deploy Website 2.
4. Drag and drop the `landing-3` folder to deploy Website 3.

### Option B: cPanel / Apache / FTP
1. Upload the files inside `landing-1/` into your first domain's `public_html/`.
2. Upload the files inside `landing-2/` into your second domain's `public_html/`.
3. Upload the files inside `landing-3/` into your third domain's `public_html/`.

### Option C: GitHub Pages
1. You can host each folder as an independent repository or under sub-paths.
